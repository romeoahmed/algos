# 表达式的所有括号组合

## 问题

输入为长度 1–20 的合法 ASCII 表达式：操作数为 0–99 的整数，以 `+`、`-`、`*` 相连，无空白、一元符号或括号。

保持操作数与运算符顺序，返回所有完整加括号方式的结果；保留重复值，输出顺序不限。

## 思路

每种括号方式对应一棵有序二叉树：叶子为操作数，内部节点为运算符，根代表最后一次运算。

枚举根运算符，递归求两侧结果，再两两组合。缓存子式以避免重复计算；单个整数返回单元素序列。

## 伪代码

[记号约定](../notation.md)。memo 仅在本次调用内共享。

```text
EXPRESSIONS(s)
    memo ← empty map

    SOLVE(t)
        if t ∈ memo
            return memo[t]
        B ← []
        for i ← 0 to |t| - 1
            if t[i] ∈ {+, -, *}
                L ← SOLVE(t[0:i]); R ← SOLVE(t[i+1:|t|])
                for a in L
                    for b in R
                        APPEND(B, APPLY(t[i], a, b))
        if B is empty
            B ← [INTEGER(t)]
        memo[t] ← B
        return B

    return SOLVE(s)
```

## 示例

`2*3-4*5` 有三种根选择：

| 根位置       | 左右子式       | 产生的结果 |
| ------------ | -------------- | ---------- |
| 第一个 `*`   | `2` 与 `3-4*5` | −34、−10   |
| `-`          | `2*3` 与 `4*5` | −14        |
| 最后一个 `*` | `2*3-4` 与 `5` | −10、10    |

最终保留五项结果，其中 −10 出现两次。

## 正确性

按运算符数量归纳：没有运算符时返回单元素序列。含运算符的括号树由根位置和左右子树唯一确定；枚举根，再组合两侧全部结果，恰好覆盖每棵树一次。不同树可能同值，故保留重复项。

## 复杂度与实现

设 m 为运算符数，括号树数量为 Catalan 数：

$$
C_0 = 1, \qquad
C_m = \sum_{i=0}^{m-1} C_i C_{m-1-i} = \frac{1}{m+1}\binom{2m}{m}.
$$

输出需 Ω(Cₘ) 时间和空间。含 r 个运算符的连续子式最多有 m−r+1 个，缓存结果总数不超过

$$
S_m = \sum_{r=0}^{m} (m-r+1)C_r = \Theta(C_m).
$$

按单位成本整数运算和哈希表平均常数次探测计，时间与额外空间均为 Θ(Cₘ)，递归深度 O(m + 1)。操作数最多两位，切片和哈希开销包含在此界内。子式虽只有 O(m²) 个，每个却可能产生多个结果，不能仅按子问题数估算。

- Python 用 `product` 组合两侧结果，`cache` 保存不可变元组，最终返回独立列表。
- C++ 用 `string_view` 表示子式，以 `bind_front` 固定运算符和左操作数，再由 `transform` 映射、`append_range` 收集结果。

缓存仅存在于本次调用。C++ 的缓存引用在重散列后仍有效，返回向量独立拥有结果。合法中间值均可由 `std::int64_t` 表示；例如 `99*99*99*99*99*0` 的最终结果为 0，中间乘积仍可能超过 32 位范围。
