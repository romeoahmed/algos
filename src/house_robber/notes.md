# 打家劫舍

## 问题

一排房屋的金额为整数序列 A。不能同时选择相邻的两间，求所选金额之和的最大值。可以一间都不选，空序列的答案为 0。

对应 LeetCode 198。原题金额非负，本实现也接受负数：负金额的房屋在最优方案中总被跳过。

## 思路

状态应当回答一个完整、可复用的子问题。令 dp[i] 表示前 i 间房屋 A[0:i] 的最大收益。考虑其中最后一间 A[i − 1]，只有两种互斥决策：

- 不选：剩下的是前 i − 1 间的子问题，收益为 dp[i − 1]；
- 选：它的左邻不能选，其余部分是前 i − 2 间的子问题，收益为 dp[i − 2] + A[i − 1]。

两种决策覆盖了所有合法方案，因此 dp[i] = MAX(dp[i − 1], dp[i − 2] + A[i − 1])。这里比较的是两个完整方案的总收益，而不是 A[i − 1] 与 A[i − 2] 这两个局部金额。“哪边金额大就先选哪边”的贪心会失败：对 `[3, 4, 3]`，先选 4 只能得到 4，最优是 3 + 3 = 6。

如果把状态定义为“必须选第 i 间时的最大收益”，它就不包含跳过第 i 间的方案：最优方案可能停在更早的位置，转移要向前查找所有 j ≤ i − 2，答案还要另外取最大值。前缀定义自动包含“选”与“不选”两类方案，答案就是 dp[n]。

边界：dp[0] = 0，空前缀没有收益。计算 dp[1] 时，选 A[0] 前面不需要跳过任何房屋，因此约定 dp[−1] = 0，得到 dp[1] = MAX(0, A[0])。dp[i] 只依赖前两项，所以只保留窗口 (dp[i − 1], dp[i])。

## 伪代码

遵循[记号约定](../notation.md)。

```text
HOUSE-ROBBER(A)
    (a, b) ← (0, 0)                // (dp[−1], dp[0])
    for x in A
        (a, b) ← (b, MAX(b, a + x))
    return b
```

## 示例

A = `[2, 7, 9, 3, 1]`：

| i     | 0   | 1   | 2   | 3   | 4   | 5   |
| ----- | --- | --- | --- | --- | --- | --- |
| dp[i] | 0   | 2   | 7   | 11  | 11  | 12  |

dp[3] = MAX(7, 2 + 9) = 11 选择第 0、2 间。dp[4] = MAX(11, 7 + 3) = 11 跳过金额 3。最终 dp[5] = MAX(11, 11 + 1) = 12，对应 2 + 9 + 1。

## 正确性

对 i 归纳证明 dp[i] 是 A[0:i] 的最大收益。i = 0 时只有空方案，收益为 0。

设 i ≥ 1，任取 A[0:i] 的一个合法方案。若它不选 A[i − 1]，它也是 A[0:i − 1] 的合法方案，收益不超过 dp[i − 1]。若选 A[i − 1]，则不选 A[i − 2]，其余部分是 A[0:i − 2] 的合法方案，收益不超过 dp[i − 2] + A[i − 1]；i = 1 时其余部分为空，收益为 0 = dp[−1]。反过来，在这两个子问题的最优方案后分别“不追加”或“追加 A[i − 1]”，都得到合法方案，两个上界均可取到，故 dp[i] 等于两者的最大值。

循环第 k 轮处理 A[k − 1] 后，(a, b) = (dp[k − 1], dp[k])。结束时 b = dp[n]。

## 复杂度与实现

单次遍历，时间 Θ(n)，额外空间 O(1)。滚动窗口丢掉了历史状态，无法回溯具体选了哪些房屋；需要输出方案时应保留完整的 dp 数组，再从 dp[n] 倒推每一步的决策。

Python 用 `functools.reduce` 折叠输入，接受 `Iterable[int]`，会完整消耗迭代器。C++ 用 `std::ranges::fold_left`，以 `std::int64_t` 累加，任意 `int` 输入在 n < 2³² 时都不会溢出。
