# 用最少箭引爆气球

## 问题

每个气球是闭区间 [start, end]，满足 start ≤ end。一支箭位于 x 时引爆所有满足 start ≤ x ≤ end 的气球，求引爆全部气球的最少箭数。空输入返回 0，允许零长度区间和重复区间。

## 思路

先看最早结束的气球：为了击中它，至少有一支箭不能越过它的右端点 e。把这支箭尽量往右放到 e，既能击中它，也为覆盖其他气球留下机会。

因为 e 是当前最小的右端点，所有候选气球的终点都不小于 e。因此只要起点 ≤ e，就一定被这支箭击中；剩下的恰好是 `start > e` 的气球，对它们重复同样的选择。

每层只传递上一支箭的位置，遍历原输入寻找未覆盖区间，不另存候选列表；箭的位置严格递增，已覆盖区间不会重新成为候选。

与[无重叠区间](../erase_overlap/notes.md)的边界条件不同：相接的两个气球 `(1, 2)`、`(2, 3)` 可以共用位于 2 的箭，因此必须用严格的 `start > e` 筛选。

不能仅按“有交集”连成一组：`[(1, 2), (2, 3), (3, 4)]` 虽然相邻区间有交集，但三者没有公共点，仍需 2 支箭。

## 伪代码

A 在调用中保持只读。NONE 表示还没有射箭；MIN-OR-NONE 对空序列返回 NONE。

```text
BURST-BALLOONS(A)
    return CHOOSE(NONE)

CHOOSE(boundary)
    ends ← [end : (start, end) ∈ A, boundary = NONE or start > boundary]
    end ← MIN-OR-NONE(ends)
    if end = NONE
        return 0
    return 1 + CHOOSE(end)
```

## 示例

`[(10, 16), (2, 8), (1, 6), (7, 12)]`：先在 6 射箭，覆盖 `(1, 6)` 与 `(2, 8)`；剩余两段用位于 12 的箭覆盖，答案为 2。

## 正确性

取最早结束的气球 g，右端点为 e。任何最优解都必须有一支箭 x ∈ g，因而 x ≤ e。将该箭向右移动至 e。原来被它击中的每个气球，起点都不大于 x，因此也不大于 e；终点又不小于最小右端点 e。所以移动后，一个原先击中的气球也不会漏掉。移动不增加箭数，因此至少存在一个最优解包含位于 e 的箭。

该箭覆盖所有起点 ≤ e 的区间，其余区间全部在 e 右侧。剩余部分必须被其他箭覆盖，递归最优解与这支箭组合即为整体最优。g 的起点不大于 e，至少 g 被删去，规模严格下降，递归终止。

## 复杂度与实现

设有 n > 0 个气球，需要 K 支箭。每选一支箭就扫描一次原输入，最后再扫描一次确认没有遗漏，共 K + 1 次。时间 O(n(K + 1))，最坏 O(n²)；只保留各层边界和迭代器，额外空间 O(K + 1)，最坏 O(n)。全部气球共用一点时为线性时间；空输入的时间、空间均为 O(1)。

课件的排序扫描版本为 O(n log n)。本实现用直接递归选择对应交换论证，保留重复扫描成本，省去候选区间的复制与分配。

Python 用生成器和 `min(default=None)`，每层生成器消耗完毕后再递归。C++ 用 `span`、`views::filter`、`views::values` 与 `ranges::min_element`，每层视图直接引用原输入，其生命周期覆盖递归调用。

没有全局状态，不修改输入。`None` / `optional` 表示尚无边界，零和整数极值都可作为真实端点。端点只比较，无差值溢出；递归受 Python 递归上限或 C++ 栈空间限制。
