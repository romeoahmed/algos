# 编辑距离

## 问题

给定字符串 a 和 b，每次操作可以插入、删除或替换一个字符，代价均为 1。求把 a 变成 b 的最少操作次数。

对应 LeetCode 72。

## 思路

与[最长公共子序列](../longest_common/notes.md)一样，需要两个独立的进度：源字符串处理到哪里，目标字符串构造到哪里。令 dp[i][j] 表示把前缀 a[0:i] 变成前缀 b[0:j] 的最少操作数。表格形状和依赖方向与最长公共子序列相同，但格子保存的是最少代价，而不是最长长度。

看两个前缀的末尾字符：

- 相同：末尾已经匹配，不必编辑，dp[i][j] = dp[i − 1][j − 1]，来自左上方。
- 不同：按最后一次操作分三种情况，各加 1：
    - 删除 a 的末尾，剩下把 a[0:i − 1] 变成 b[0:j]，来自上方 dp[i − 1][j]；
    - 插入 b 的末尾，剩下把 a[0:i] 变成 b[0:j − 1]，来自左方 dp[i][j − 1]；
    - 把 a 的末尾替换为 b 的末尾，剩下两个更短的前缀，来自左上方 dp[i − 1][j − 1]。

删除来自上方，是因为源前缀先缩短；插入来自左方，是因为目标前缀先缩短。

空前缀不是“没有状态”，而是统一递推所需的基础子问题：长度 i 的前缀变成空串只能删除 i 次，dp[i][0] = i；空串变成长度 j 的前缀只能插入 j 次，dp[0][j] = j。

每行只依赖上一行和本行左侧，因此只需保存一行。把 a 变成 b 的每一步操作反过来做（插入与删除互换，替换仍为替换），就得到把 b 变成 a 的同样长的操作序列，所以答案对两个字符串对称。让较短的字符串作为列，额外空间只需 O(min(m, n))。

## 伪代码

遵循[记号约定](../notation.md)。

```text
EDIT-DISTANCE(a, b)
    if |a| < |b|
        (a, b) ← (b, a)    // b 为较短者，作为列
    R ← [j : j ∈ [0:|b| + 1)]
    for c in a
        R′ ← [R[0] + 1]
        for j ← 1 to |b|
            if c = b[j − 1]
                APPEND(R′, R[j − 1])
            else
                APPEND(R′, 1 + MIN(R[j − 1], R[j], R′[j − 1]))
        R ← R′
    return R[|b|]
```

新行中，R[j − 1] 是左上方，R[j] 是上方，R′[j − 1] 是刚算出的左方。

## 示例

a = `horse`，b = `ros`：

| a 前缀 \ b 前缀 | ""  | r   | ro  | ros |
| --------------- | --- | --- | --- | --- |
| ""              | 0   | 1   | 2   | 3   |
| h               | 1   | 1   | 2   | 3   |
| ho              | 2   | 2   | 1   | 2   |
| hor             | 3   | 2   | 2   | 2   |
| hors            | 4   | 3   | 3   | 2   |
| horse           | 5   | 4   | 4   | 3   |

例如 dp[2][2] 比较 `ho` 与 `ro`，末尾 o 相同，直接取左上方 dp[1][1] = 1，即把 h 替换为 r。右下角为 3，一种操作序列是：把 h 替换为 r 得到 `rorse`，删除第二个 r 得到 `rose`，再删除 e 得到 `ros`。

## 正确性

最优操作序列不会对同一个位置反复修改，因此可以看成把 a 与 b 按顺序对齐：每一列是 a 的一个字符对 b 的一个字符（相同代价 0，不同即替换，代价 1）、a 的字符对空（删除）或空对 b 的字符（插入），总代价是非零列的个数。

对 i + j 归纳。a[0:i] 与 b[0:j] 的任一对齐，最后一列只有三种：删除 a[i − 1]，其余是 a[0:i − 1] 与 b[0:j] 的对齐；插入 b[j − 1]，其余是 a[0:i] 与 b[0:j − 1] 的对齐；a[i − 1] 对 b[j − 1]，其余是两个更短前缀的对齐。三种情况的最优值分别是 dp[i − 1][j] + 1、dp[i][j − 1] + 1，以及 dp[i − 1][j − 1] 加上末列代价（末尾相同为 0，不同为 1），dp[i][j] 取其中最小者。

末尾不同时，这就是转移式。末尾相同时，第三项为 dp[i − 1][j − 1]，还需说明它不大于另外两项：先把 a[0:i − 1] 变成 b[0:j]，再删去末尾的 b[j − 1]，就把 a[0:i − 1] 变成了 b[0:j − 1]，所以 dp[i − 1][j − 1] ≤ dp[i − 1][j] + 1；先在 a[0:i − 1] 末尾插入 a[i − 1]，再把 a[0:i] 变成 b[0:j − 1]，所以 dp[i − 1][j − 1] ≤ dp[i][j − 1] + 1。因此末尾相同时直接取左上方即可。

测试从 a 出发，按层广度优先地尝试所有单步编辑，到达 b 的层数即最少操作数，作为独立的参考方法。按对齐看，任一最优序列都可以先删除、再替换、最后插入，中间字符串不会长于两者中较长的一个，搜索据此限制长度，字符也只取自两个字符串。

## 复杂度与实现

共 (m + 1)(n + 1) 个状态，每格比较一次字符并取至多三个值的最小值，时间 Θ(mn)，额外空间 Θ(min(m, n))。只保存一行意味着无法给出具体的操作序列；需要时应保留整张表，从右下角沿转移来源倒推。

实现结构与最长公共子序列相同。Python 用 `functools.reduce` 逐字符折叠较长的字符串，`itertools.pairwise` 给出 (左上方, 上方)，`itertools.accumulate` 以 R[0] + 1 为初值从左向右扫描。字符按 Unicode 码位比较。

C++ 用 `std::views::iota` 生成第 0 行，`std::ranges::fold_left` 逐字符折叠较长的字符串，每步追加构造新行，峰值同时存在两行。`std::string_view` 按字节比较，多字节 UTF-8 字符的一次修改可能计为多次字节编辑。
