# 第 k 大元素

## 问题

输入为非空整数序列，保证 `1 ≤ k ≤ n`。返回第 k 大的值，重复值分别计入排名。输入保持不变。

## 思路

取中间位置的值作为枢轴 p。`PARTITION` 返回大于 p 的组 G 和小于 p 的组 L；其余元素都等于 p，无需另建一组。

设 u = n − |L|，即大于或等于 p 的元素数：

- k ≤ |G|：递归求 G 的第 k 大。
- |G| < k ≤ u：返回 p。
- k > u：递归求 L 的第 k − u 大。

分组构造子问题，选择判断目标排名；每次只递归进入一组。

## 伪代码

[记号约定](../notation.md)。

```text
PARTITION(A, p)
    return ([x : x ∈ A, x > p], [x : x ∈ A, x < p])

QUICKSELECT(A, k)
    p ← A[⌊|A| / 2⌋]
    (G, L) ← PARTITION(A, p)
    u ← |A| - |L|
    if k ≤ |G|
        return QUICKSELECT(G, k)
    if k ≤ u
        return p
    return QUICKSELECT(L, k - u)
```

## 示例

`[3, 1, 3, 2]` 取 p = 3，得到 G = `[]`、L = `[1, 2]`，u = 2。第 2 大就是 3；第 3 大转为 L 的第 1 大，得到 2。

## 正确性

大于、等于、小于枢轴的元素对应三段连续的降序排名。筛选保留每个元素的出现次数，按组大小定位和换算排名不会改变目标。

枢轴来自当前输入，等于组非空。每次返回或递归进入严格更小的非空组，故递归终止；单元素输入自然落在等于组。

## 复杂度与实现

一次分组的耗时与当前组长度成正比。随机排列输入下平均时间 O(n)，最坏 O(n²)。中间位置的值未必接近中位数，固定枢轴不保证任意输入下的期望线性时间。

递归保留父层的分组副本。均衡缩减时额外空间 O(n)、深度 O(log n)；最坏额外空间 O(n²)、深度 O(n)。全相等输入只需一层。

Python 用列表推导式分组；C++ 用 `views::filter` 与 `ranges::to`，通过只读 `span` 访问输入。分组向量在递归返回前保持存活。较深的递归受 Python 递归上限或 C++ 可用栈空间限制。
