# 无重叠区间

## 问题

给定有限区间序列，每个区间满足 start < end。删除尽可能少的区间，使剩余区间互不重叠。端点相接允许共存：`(1, 2)` 与 `(2, 3)` 不重叠。可按半开区间 [start:end) 理解；空输入返回 0。

## 思路

把“删除最少”换成“保留最多”更容易思考：最少删除数 = 总数 − 最多保留数。

每次保留结束最早的区间。它尽早让出时间，能给后面的区间留下最多选择。选定终点 e 后，后续区间只需满足 `start ≥ e`，于是又得到一个同样的问题。

最早开始可能占用过长时间：`[(0, 10), (1, 2), (2, 3)]` 应保留后两段。最短区间也可能堵住两侧：`[(0, 3), (2, 4), (3, 6)]` 应保留第一、三段。

只需传递上次选择的终点 boundary。每层遍历原序列，只考虑 `start ≥ boundary` 的候选，再取最小终点；筛选时不另存候选列表。边界严格递增，先前排除的区间不会重新成为候选。相同终点任选一段即可，它们留下的后续候选相同。

## 伪代码

A 在调用中保持只读。NONE 表示尚无边界；MIN-OR-NONE 对空序列返回 NONE。

```text
ERASE-OVERLAP(A)
    return |A| − CHOOSE(NONE)

CHOOSE(boundary)
    ends ← [end : (start, end) ∈ A, boundary = NONE or start ≥ boundary]
    end ← MIN-OR-NONE(ends)
    if end = NONE
        return 0
    return 1 + CHOOSE(end)
```

## 示例

`[(1, 2), (2, 3), (3, 4), (1, 3)]` 先选 `(1, 2)`，留下 `(2, 3)`、`(3, 4)`；最终保留 3 个，删除 1 个。

## 正确性

任取一个最多保留区间的安排，按时间顺序记首段为 o。贪心区间 g 满足 g.end ≤ o.end。原本接在 o 后面的区间都满足 start ≥ o.end，自然也满足 start ≥ g.end。因此用 g 替换 o 后，后续区间仍能保留，数量不变，因此至少存在一个最优安排从 g 开始。

选定 g 后，所有后续区间恰好来自起点不早于 g.end 的候选，构成同类子问题。对子问题规模归纳，递归求出的保留数最多，相减得到的删除数最少。因为 g.start < g.end，g 必被筛掉，子问题严格缩小，递归终止。

## 复杂度与实现

设有 n > 0 个区间，最多保留 K 个。每选一段就扫描一次原输入，最后还需一次扫描确认结束，共 K + 1 次。时间为 O(n(K + 1))，最坏 O(n²)。每层只保留边界和迭代器，额外空间 O(K + 1)，最坏 O(n)。空输入的时间、空间均为 O(1)。

课件先按终点排序再扫描，时间 O(n log n)。这里保留直接递归选择以对应交换论证，承担重复扫描成本，但不再复制候选区间。

Python 用生成器表达式与 `min(default=None)`；生成器在进入下一层前消耗完毕。C++ 用只读 `span`、`views::filter`、`views::values` 与 `ranges::min_element`，以空范围表示没有候选。每层视图直接引用调用者输入，调用期间不复制区间。

端点仅比较，不做减法；`None` / `optional` 表示无边界，不占用整数端点值。递归不是尾调用，受 Python 递归上限或 C++ 栈空间限制。
