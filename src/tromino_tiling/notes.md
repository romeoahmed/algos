# 缺一格棋盘覆盖

## 问题

给定边长 n = 2ᵏ（k ≥ 0）的棋盘和一个缺格 hole，用可旋转的 L 形骨牌恰好覆盖其余各格。每块骨牌覆盖某个 2×2 方块中的三格，不允许重叠或覆盖缺格。

坐标从 0 开始，hole 的行、列均在 `[0, n)` 内。返回骨牌序列，每块由三个格子的坐标表示，骨牌及其内部坐标的顺序不限。n = 1 时返回空序列。需要编号时，可将返回序列的下标作为骨牌编号。

## 思路

把棋盘分成四个象限后，只有一个象限缺格，另外三个还不能套用同一道题的解法。

在中心放一块 L 形骨牌，让它在另外三个象限各占一格。对子问题来说，已经占用的格子与原缺格一样，都不能再覆盖。这样，四个象限就都变成了“缺一格的小棋盘”，可以递归求解。边长为 1 时，只剩缺格，无需放骨牌。

递归只需传入区域左上角、边长和缺格。将新骨牌追加到本次调用独有的输出缓冲区，四个象限共用该缓冲区；无需维护棋盘数组或全局编号。

## 伪代码

遵循[记号约定](../notation.md)。四象限依次为左上、右上、左下、右下。

```text
TROMINO-TILING(n, hole)
    tiles ← []

    COVER(origin, side, missing)
        if side = 1
            return
        (top, left) ← origin
        h ← side / 2
        q ← 2 · INTEGER(missing.row ≥ top + h)
             + INTEGER(missing.column ≥ left + h)
        centers ← [(top+h−1, left+h−1), (top+h−1, left+h),
                   (top+h, left+h−1),   (top+h, left+h)]
        APPEND(tiles, [centers[i] : i ∈ [0, 1, 2, 3], i ≠ q])
        for i ← 0 to 3
            next ← missing if i = q else centers[i]
            COVER((top + ⌊i/2⌋·h, left + (i mod 2)·h), h, next)

    COVER((0, 0), n, hole)
    return tiles
```

这里 `INTEGER(条件)` 表示条件成立时取 1，否则取 0。

## 示例

n = 4，缺格为 `(0, 0)`。先放中心骨牌 A，再分别用 B、C、D、E 覆盖四个 2×2 子棋盘：

```text
× B C C
B B A C
D A A E
D D E E
```

× 是原缺格，相同字母表示同一块骨牌。A 占据另外三个象限的一角，后续递归避开这些格子，最终共用五块骨牌。

```python
from src.tromino_tiling.solution import Cell, tromino_tiling

tiles = tromino_tiling(4, Cell(0, 0))
print(len(tiles))  # 5
```

## 正确性

对边长归纳。边长 1 时唯一方格就是缺格，空覆盖正确。

边长更大时，中心骨牌由中心 2×2 方块的三格组成，确为 L 形，而且避开原缺格所在象限。各象限分别保留原缺格或将中心已覆盖格作为缺格，均满足递归前提。

由归纳假设，递归覆盖每个象限除指定缺格外的全部格子，且不重叠。象限互不相交，中心三格又不被递归覆盖，因此合起来恰好覆盖整个棋盘除原缺格外的全部格子。边长每次减半，最终终止。

## 复杂度与实现

每次非基例调用执行常数工作并递归进入四个象限，T(n) = 4T(n/2) + Θ(1)。n ≥ 2 时，时间 Θ(n²)，输出恰有 (n²−1)/3 块骨牌，已达到输出规模下界。

额外空间计入输出，为 Θ(n²)；除输出外，递归栈为 O(log n)。每层只保留常数个坐标。输出集中追加到调用内缓冲区，避免逐层拼接递归结果的复制成本。

- Python 最后把列表转为不可变元组，需要 Θ(n²) 次引用复制，不改变总体复杂度。
- C++ 用 `filter` 排除缺格所在象限，`transform` 生成中心坐标，`ranges::copy` 写入三格骨牌。向量追加的摊销成本为常数，返回结果独立拥有坐标。

两种实现都保留输入，调用之间不共享状态。递归深度随 k 增长，受 Python 递归上限或 C++ 栈空间限制，不调整递归上限；坐标和分配大小须能由机器表示，实际规模还受输出内存限制。

测试检查每块的 L 形几何性质、总块数，以及所有非缺格恰好出现一次；穷举小棋盘的全部缺格，并随机生成更大的合法棋盘，不限定某种铺法或编号。
