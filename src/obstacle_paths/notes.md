# 不同路径 II

## 问题

机器人位于 m × n 网格的左上角，m、n ≥ 1，每次只能向右或向下移动一格。部分格子是障碍，用 `#` 标记，不能进入；其余格子用 `.` 标记。求到达右下角的不同路径数。起点或终点本身也可能是障碍，此时答案为 0。

对应 LeetCode 63。

## 思路

状态与[不同路径](../unique_paths/notes.md)相同：dp[i][j] 表示从起点到达格子 (i, j) 的路径数，仍由行、列两个坐标共同确定。障碍没有改变普通格的转移，只是让一部分状态失效：

- 障碍格不能进入，dp[i][j] = 0；
- 普通格的最后一步来自上方或左方，dp[i][j] = dp[i − 1][j] + dp[i][j − 1]，越界的前驱按 0 计。

障碍格为 0 的效果会向后传播：经过它的路径全部被切断。首行出现障碍后，它右侧的格子只能从左边到达，因此全部变为 0；首列同理。所以首行首列不能再像无障碍时那样直接设为 1。

边界也可以统一处理：假想网格上方还有一行，只在起点正上方有一条路径。这样起点若可进入就得到 0 + 1 = 1，若是障碍就得到 0，首行与首列都由同一条转移式算出，无需单独初始化。

逐行计算时只需保存一行 R，并且可以原地更新：从左到右处理第 j 格时，更新前的 R[j] 是上方的值，R[j − 1] 已是本行左方的值。障碍格必须显式清零，否则旧的“上方路径”会错误地穿过障碍。

## 伪代码

遵循[记号约定](../notation.md)。

```text
OBSTACLE-PATHS(G)
    n ← |G[0]|
    R ← [1] ⧺ [0 : j ∈ [1:n)]    // 虚拟的上一行把一条路径送入起点
    for row in G
        left ← 0
        for j ← 0 to n − 1
            if row[j] = '#'
                R[j] ← 0
            else
                R[j] ← left + R[j]
            left ← R[j]
    return R[n − 1]
```

## 示例

3 × 3 网格，中心是障碍：

| i \ j | 0   | 1   | 2   |
| ----- | --- | --- | --- |
| 0     | 1   | 1   | 1   |
| 1     | 1   | 0   | 1   |
| 2     | 1   | 1   | 2   |

中心为 0，所以 (1, 2) 只能从上方得到 1，(2, 1) 只能从左方得到 1，右下角为 2：两条路径分别沿上边和右边、沿左边和下边绕过障碍。

若网格为 `.#.` 与 `...` 两行，首行在 (0, 1) 被切断，第一行算得 `[1, 0, 0]`；第二行为 `[1, 1, 1]`，唯一的路径先向下再一路向右。

## 正确性

不变量：处理完第 i 行后，R[j] 是从起点到达 (i, j) 且不经过障碍的路径数。

把虚拟行看作第 −1 行，它只在第 0 列有一条“路径”，作用是让起点满足与普通格相同的转移。设第 i 行之前 R[j] 是到达 (i − 1, j) 的路径数（i = 0 时为虚拟行）。处理 (i, j) 时：若是障碍，没有路径能进入，值为 0；否则，到达它的路径（起点本身除外）按最后一步分为来自上方和来自左方两类，互斥且覆盖全部情况，分别有 R[j] 和 left 条，left 是本行刚算出的 (i, j − 1)，j = 0 时左方越界为 0。起点处上方的 1 恰好计入只含起点的那条路径。

每条路径恰好包含 m − 1 次向下和 n − 1 次向右。测试枚举这些移动的全部排列，逐格走一遍，统计不碰到障碍的条数，作为独立的参考方法。

## 复杂度与实现

每格 O(1)，时间 Θ(mn)，额外空间 Θ(n)。与无障碍版本不同，这里不按较短的一维滚动：输入按行给出，转置需要复制整个网格。

有障碍时，每格的路径数都不超过无障碍网格同一格的路径数，而后者沿行和列单调不减，不超过右下角的值。所以只要同样大小的无障碍网格的答案可表示，所有中间值都可表示，例如 34 × 34 以内的任意网格。即使终点是障碍、答案为 0，中间格子仍可能很大，因此 C++ 的前提按网格大小而不是答案来表述。

Python 用 `functools.reduce` 逐行折叠网格，每行由 `itertools.accumulate` 以 0 为初值从左向右扫描，累积值就是左方；去掉初值后得到新行。函数读取首行长度，接受 `Sequence[str]`。

C++ 用 `std::ranges::fold_left` 逐行折叠，累积的行被移入下一步，在 `std::views::zip(row, paths)` 上原地更新，`left` 保存本行左方的值，与伪代码一致。计数使用 `std::uint64_t`。
