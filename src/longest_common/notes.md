# 最长公共子序列

## 问题

给定字符串 a 和 b，求它们最长公共子序列的长度。子序列可以删除字符，但必须保持原有的相对顺序，不要求连续；公共子序列须同时是 a 和 b 的子序列。任一字符串为空时答案为 0。

对应 LeetCode 1143。

## 思路

只记 a 的处理位置不够：同样匹配到 a 的第 i 个字符，b 可能已经用掉了不同数量的字符，后面还能匹配的部分也不同。只记 b 的位置同理。两个进度可以独立变化，因此令 dp[i][j] 表示前缀 a[0:i] 与 b[0:j] 的最长公共子序列长度。每个格子回答的是两个前缀之间的最优关系，而不只是两个字符是否相等。

看两个前缀的末尾字符 a[i − 1] 与 b[j − 1]：

- 相同：这个共同字符可以作为公共子序列的最后一个字符。去掉它后剩下两个更短的前缀，dp[i][j] = dp[i − 1][j − 1] + 1，来自左上方。
- 不同：两个末尾字符不能同时进入公共子序列，至少有一个可以舍弃。舍弃 a 的末尾得到 dp[i − 1][j]（上方），舍弃 b 的末尾得到 dp[i][j − 1]（左方），取较大者。这里不能直接取左上方：最优解可能只需舍弃其中一个末尾，两个都舍弃会丢掉答案。

第 0 行和第 0 列表示其中一个前缀为空，公共子序列只能为空，值为 0。每格依赖上方、左方和左上方，按从上到下、从左到右的顺序填表，三个前驱都已算出。

每行只依赖上一行和本行左侧，因此只需保存一行。交换 a 与 b 相当于把表转置，答案不变，所以让较短的字符串作为列，另一个逐字符决定新行，额外空间只需 O(min(m, n))。

## 伪代码

遵循[记号约定](../notation.md)。

```text
LONGEST-COMMON(a, b)
    if |a| < |b|
        (a, b) ← (b, a)    // b 为较短者，作为列
    R ← [0 : j ∈ [0:|b| + 1)]
    for c in a
        R′ ← [0]
        for j ← 1 to |b|
            if c = b[j − 1]
                APPEND(R′, R[j − 1] + 1)
            else
                APPEND(R′, MAX(R[j], R′[j − 1]))
        R ← R′
    return R[|b|]
```

新行中，R[j − 1] 是左上方，R[j] 是上方，R′[j − 1] 是刚算出的左方。

## 示例

a = `abcde`，b = `ace`：

| a 前缀 \ b 前缀 | ""  | a   | ac  | ace |
| --------------- | --- | --- | --- | --- |
| ""              | 0   | 0   | 0   | 0   |
| a               | 0   | 1   | 1   | 1   |
| ab              | 0   | 1   | 1   | 1   |
| abc             | 0   | 1   | 2   | 2   |
| abcd            | 0   | 1   | 2   | 2   |
| abcde           | 0   | 1   | 2   | 3   |

a 与 a、c 与 c、e 与 e 相同时，都由左上方加 1；其余格子取上方与左方的较大值。右下角为 3，对应 `ace`。

## 正确性

对 i + j 归纳，证明转移式给出 dp[i][j]。任取 a[0:i] 与 b[0:j] 的一个公共子序列 S，固定它在两个字符串中的一种匹配位置。

末尾相同时：去掉 S 的最后一个字符，其余字符匹配在两个末尾之前，是 a[0:i − 1] 与 b[0:j − 1] 的公共子序列，所以 |S| ≤ dp[i − 1][j − 1] + 1。反过来，在后者的最优解末尾接上共同字符，就得到长度 dp[i − 1][j − 1] + 1 的公共子序列，上界可以取到。

末尾不同时：若 S 同时用到 a[i − 1] 和 b[j − 1]，二者都只能匹配 S 的最后一个字符，与末尾不同矛盾。所以 S 至少不用其中一个，是 (a[0:i − 1], b[0:j]) 或 (a[0:i], b[0:j − 1]) 的公共子序列，|S| 不超过二者的较大值；两个子问题的最优解本身也是当前前缀的公共子序列，可以取到。

测试枚举 a 的全部子序列，保留能在 b 中按顺序找到的最长者，作为独立的参考方法，并检查交换参数后答案不变。

## 复杂度与实现

共 (m + 1)(n + 1) 个状态，每格比较一次字符并取一次最大值，时间 Θ(mn)，额外空间 Θ(min(m, n))。只保存一行意味着只能得到长度；需要具体的子序列时应保留整张表，从右下角沿转移来源倒推。

Python 先用稳定排序取出较短的字符串，再用 `functools.reduce` 逐字符折叠较长的字符串。`itertools.pairwise(above)` 为每一列给出 (左上方, 上方)，`itertools.accumulate` 以 0 为初值从左向右扫描，累积值就是左方。每步构造新行，峰值同时存在两行。字符按 Unicode 码位比较。

C++ 用 `std::ranges::minmax` 按长度取出两个字符串，长度相同时保持原顺序。`std::ranges::fold_left` 逐字符折叠较长的字符串，每步由 `std::views::zip` 和 `std::views::pairwise` 读取上一行，追加构造新行，`row.back()` 就是左方，峰值同时存在两行。`std::string_view` 按字节比较，多字节 UTF-8 字符按其字节序列参与匹配。
