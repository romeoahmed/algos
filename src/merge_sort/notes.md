# 归并排序

## 问题

返回整数序列的非降序副本，保留相等元素的原有次序。允许空序列和重复值。

## 思路

长度不足 2 时返回副本；否则平分为两半，递归排序后归并。

归并时比较两侧尚未输出的首项，取较小者；相等时先取左侧，以保持稳定性。一侧耗尽后接上另一侧。

## 伪代码

[记号约定](../notation.md)。

```text
MERGE-SORT(A)
    if |A| < 2
        return COPY(A)
    m ← ⌊|A| / 2⌋
    return MERGE(MERGE-SORT(A[0:m]), MERGE-SORT(A[m:|A|]))

MERGE(L, R)
    B ← []; i ← 0; j ← 0
    while i < |L| and j < |R|
        if L[i] ≤ R[j]
            APPEND(B, L[i]); i ← i + 1
        else
            APPEND(B, R[j]); j ← j + 1
    return B ⧺ L[i:|L|] ⧺ R[j:|R|]
```

## 示例

`[3, 1, 2, 1]` 分为 `[3, 1]` 与 `[2, 1]`，递归得到 `[1, 3]` 与 `[1, 2]`。归并依次取左侧的 1、右侧的 1、右侧的 2，最后接上 3，得到 `[1, 1, 2, 3]`。

## 正确性

归并过程中，B 始终有序，且不大于两侧剩余元素。每步取最小的剩余元素，保持此性质；最后接上余项，恰好覆盖全部输入。

对长度归纳：长度不足 2 时成立；两半递归有序后，归并得到完整有序序列。两半内部稳定，跨两半的相等元素先取左侧，因此整体稳定。

## 复杂度与实现

T(n) = T(⌊n/2⌋) + T(⌈n/2⌉) + Θ(n)，故时间 Θ(n log n)，额外空间 Θ(n)，递归深度 Θ(log n)。

两种实现都由递归排序和内部归并函数组成，只修改局部输出。Python 用下标推进两侧游标；C++ 用只读 `span` 推进子视图，以 `append_range` 接上余项。子结果在归并完成前保持存活，返回值独立拥有数据。
