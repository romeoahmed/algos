# 归并排序

## 问题

返回整数序列的非降序副本，保留相等元素的原有次序。允许空序列和重复值。

## 思路

直接排序整个序列不容易，但合并两个已经有序的序列很容易：整体最小值一定是某一侧的首项，比较两侧首项、取出较小者，再对剩余部分重复即可，每次比较都输出一个元素，总共线性时间。

因此把序列平分为两半，分别递归排序，再归并两个有序结果。长度不足 2 的序列本身有序，直接返回副本，作为递归的终点。

归并时两侧首项相等，先取左侧。左侧元素在输入中位于右侧之前，这样相等元素保持原有次序，排序是稳定的。一侧耗尽后，另一侧的剩余部分已经有序且不小于已输出的元素，直接接上。

## 伪代码

遵循[记号约定](../notation.md)。

```text
MERGE-SORT(A)
    if |A| < 2
        return COPY(A)
    m ← ⌊|A| / 2⌋
    return MERGE(MERGE-SORT(A[0:m]), MERGE-SORT(A[m:|A|]))

MERGE(L, R)
    B ← []; i ← 0; j ← 0
    while i < |L| and j < |R|
        if L[i] ≤ R[j]
            APPEND(B, L[i]); i ← i + 1
        else
            APPEND(B, R[j]); j ← j + 1
    return B ⧺ L[i:|L|] ⧺ R[j:|R|]
```

## 示例

`[3, 1, 2, 1]` 分为 `[3, 1]` 与 `[2, 1]`，递归得到 `[1, 3]` 与 `[1, 2]`。归并依次取左侧的 1、右侧的 1、右侧的 2，最后接上 3，得到 `[1, 1, 2, 3]`。

## 正确性

归并的不变量：B 有序，且 B 中的元素都不大于两侧剩余的元素。两侧各自有序，剩余部分的最小值就是两个首项中的较小者，把它追加到 B 末尾后不变量仍成立。循环结束时一侧已空，另一侧的余项有序且不小于 B 中元素，接上后得到包含全部输入的有序序列。

对长度归纳：长度不足 2 时副本即有序。否则两半更短，由归纳假设递归后有序，归并得到完整的有序序列。稳定性同理：同一半内的相等元素由归纳假设保持次序，跨两半的相等元素归并时先取左侧，因此整体稳定。

## 复杂度与实现

T(n) = T(⌊n/2⌋) + T(⌈n/2⌉) + Θ(n)，故时间 Θ(n log n)，额外空间 Θ(n)，递归深度 Θ(log n)。

两种实现都由递归排序和内部归并函数组成，只修改局部输出。Python 用下标推进两侧游标，再用 `extend` 接上余项，直接返回该列表，避免再次复制已有输出。递归切片和剩余切片会复制引用，仍计入上述时间、空间界。

C++ 用只读 `span` 推进子视图，按两段总长预留输出容量，再以 `append_range` 接上余项。子视图不复制元素，子结果在归并完成前保持存活，返回向量独立拥有数据。

递归结果还需归并，因此不是尾递归；Python 受递归上限限制，C++ 受可用栈空间限制。
