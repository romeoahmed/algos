# 搜索旋转数组

## 问题

输入为严格递增整数序列旋转后的结果，允许空序列。返回目标下标，未找到时返回 −1。

## 思路

旋转序列至多有一个下降断点。检查中点 m 后，至少能确定一侧有序：

- 若 A[l] ≤ A[m]，左半区有序。目标在 `[A[l], A[m])` 内时保留左侧，否则保留右侧。
- 否则右半区有序。目标在 `(A[m], A[r−1]]` 内时保留右侧，否则保留左侧。

中点已检查，后续区间将其排除。

## 伪代码

[记号约定](../notation.md)。搜索区间为 `[l, r)`。

```text
ROTATED-SEARCH(A, x)
    SEARCH(l, r)
        if l = r
            return -1
        m ← l + ⌊(r - l) / 2⌋
        if A[m] = x
            return m
        if A[l] ≤ A[m]
            keep-left ← A[l] ≤ x < A[m]
        else
            keep-left ← not (A[m] < x ≤ A[r - 1])
        if keep-left
            return SEARCH(l, m)
        return SEARCH(m + 1, r)

    return SEARCH(0, |A|)
```

## 示例

在 `[4, 5, 6, 7, 0, 1, 2]` 中查找 0：

| 下标区间 | 中点值 | 判断                    | 下一步            |
| -------- | ------ | ----------------------- | ----------------- |
| `[0, 7)` | 7      | 0 不在左侧值域 `[4, 7)` | 保留下标 `[4, 7)` |
| `[4, 7)` | 1      | 0 在左侧值域 `[0, 1)`   | 保留下标 `[4, 5)` |
| `[4, 5)` | 0      | 命中目标                | 返回下标 4        |

## 正确性

递归保持：若目标存在，就在当前区间内。有序半区的端点确定目标是否可能落在其中，据此排除另一侧或该半区。

每步返回结果或缩短区间；空区间返回 −1，单元素区间只检查一次。

元素互异是必要前提：`[1, 0, 1, 1, 1]` 的端点和中点均为 1，无法用同一规则判断断点所在侧。

## 复杂度与实现

每次递归最多保留约一半元素，时间 O(log n)，递归栈占 O(log n) 空间。

Python 传递半开下标区间；C++ 传递只读 `span` 和原数组偏移，不复制元素。中点由半段长度计算，结果下标由偏移还原。
