# 跳跃游戏 II

## 问题

给定非空非负整数序列 A，A[i] 表示从 i 最多向右跳多少格。起点为 0，保证最后一个位置可达，求最少跳跃次数。长度为 1 时返回 0。

## 思路

先换一个问法：跳 1 次能覆盖到哪里？跳 2 次呢？把最少需要相同跳数才能到达的位置放在一层，就不必逐一枚举完整路径。

初始层只有下标 0，即 [0:1)。扫描当前层 [first:stop)，比较每个位置的 `i + A[i]`，得到下一跳能覆盖的最远位置。右边界 following 比这个位置大 1，新增的一层就是 [stop:following)。终点第一次被覆盖时，所用跳数最少。

“直接落到最远位置”会失败：对于 `[2, 3, 0, 0, 0]`，先跳到下标 2 会停住，而 0 → 1 → 4 只需两跳。应最大化下一层覆盖，不必提前决定具体落点。

## 伪代码

以下函数共享只读 A；边界截断至 n，避免扫描终点外的位置。

```text
JUMP-GAME(A)
    n ← |A|
    return EXPAND(0, 1, 0)

EXPAND(first, stop, jumps)
    if stop = n
        return jumps
    following ← MIN(n, 1 + MAX([i + A[i] : i ∈ [first:stop)]))
    return EXPAND(stop, following, jumps + 1)
```

## 示例

以 `[2, 3, 1, 1, 4]` 为例：

| 最少跳数 | 本层首次可达的下标 | 展开结果                     |
| -------- | ------------------ | ---------------------------- |
| 0        | 0                  | 从 0 最远到 2，下一层是 1、2 |
| 1        | 1、2               | 最远可到 4，下一层是 3、4    |
| 2        | 3、4               | 已包含终点，返回 2           |

这里记录的是一层可选的落点，并不表示要依次经过层内每个位置。

## 正确性

不变量：调用 `EXPAND(first, stop, jumps)` 时，[0:stop) 恰是至多 jumps 跳可达的所有位置，[first:stop) 中的位置首次需要 jumps 跳。

初始仅下标 0 可达，不变量成立。更早层能够带来的覆盖已计入 stop；从当前层任一位置可向右跳不超过 A[i] 格，因此新增可达位置连续，其右边界恰为 following。扫描当前层所有位置取最大值既不遗漏可达位置，也不引入不可达位置，所以递归后不变量保持。

终点首次位于 [0:stop) 时，少一跳尚不可达，返回值最小。可达性前提保证未到终点时 following > stop，故递归终止。

## 复杂度与实现

每个位置至多扫描一次，时间 O(n)。设答案为 J，递归深度和额外空间均为 O(J + 1)，最坏 O(n)；循环扫描版本则只需 O(1) 额外空间。

Python 用生成器表达式与 `max` 聚合当前层，不复制输入或切片，要求序列支持常数时间的下标访问。C++ 的 `reach` 计算单个位置可达的右边界，`iota`、`transform` 与 `max` 聚合当前层；先将步长截断到剩余距离，再相加，允许步长达到 `size_t` 的最大值而不溢出。

递归调用位于尾部，但 Python 不消除尾调用，C++ 也不保证尾调用优化。长的逐格跳跃输入受 Python 递归上限或 C++ 栈空间限制，不调整递归上限。Python 大整数加法和比较的实际成本另计。
