# 爬楼梯

## 问题

楼梯共 n 阶，n ≥ 0。每次向上走 1 阶或 2 阶，求从地面（第 0 阶）恰好到达第 n 阶的不同走法数。步长顺序不同算作不同走法。n = 0 时只有空走法，答案为 1。

对应 LeetCode 70。

## 思路

令 dp[i] 表示从第 0 阶恰好到达第 i 阶的走法数。按最后一步分类：

- 最后走 1 阶：此前恰好到达第 i − 1 阶，有 dp[i − 1] 种；
- 最后走 2 阶：此前恰好到达第 i − 2 阶，有 dp[i − 2] 种。

每种走法的最后一步必是其中之一，同一走法也不会同时落入两类，因此两类互斥且覆盖全部走法，计数用加法合并：dp[i] = dp[i − 1] + dp[i − 2]。

直接按这个式子递归，同一个 dp[j] 会在不同分支中反复出现：调用次数与 dp[n] 同阶，按指数增长。但不同的子问题只有 n + 1 个，而且只要站在同一台阶上，后面要解决的问题与之前怎样走上来无关。状态只需记录台阶编号，按 i 递增的顺序把每个状态算一次即可。

dp[i] 只依赖前两项，所以只保留窗口 (dp[i − 1], dp[i])，每算一项就整体右移一格。为了让 i = 1 也使用同一个转移，约定 dp[−1] = 0：不存在的台阶没有走法。于是 dp[1] = dp[0] + dp[−1] = 1，初值只需 (0, 1)，n = 0 与 n = 1 都不必特判。

dp[0] = 1 并不表示“有一个动作”。它表示空走法：其他走法都由它逐步追加步长得到。

## 伪代码

遵循[记号约定](../notation.md)。

```text
CLIMBING-STAIRS(n)
    (a, b) ← (0, 1)            // (dp[−1], dp[0])
    for i ← 1 to n
        (a, b) ← (b, a + b)    // (dp[i − 1], dp[i])
    return b
```

## 示例

n = 4 时：

| i     | 0   | 1   | 2   | 3   | 4   |
| ----- | --- | --- | --- | --- | --- |
| dp[i] | 1   | 1   | 2   | 3   | 5   |

5 种走法为 1+1+1+1、1+1+2、1+2+1、2+1+1、2+2。前三种最后走 1 阶，对应 dp[3] = 3；后两种最后走 2 阶，对应 dp[2] = 2。

## 正确性

不变量：第 i 轮开始前，(a, b) = (dp[i − 2], dp[i − 1])。

第 1 轮开始前，(a, b) = (0, 1) = (dp[−1], dp[0])。第 i 轮把窗口改为 (dp[i − 1], dp[i − 2] + dp[i − 1])，由转移式即为 (dp[i − 1], dp[i])，不变量对下一轮成立。循环结束时 b = dp[n]。

按 2 阶步的个数 k 分类，还可以得到组合恒等式 dp[n] = Σ C(n − k, k)，其中 0 ≤ k ≤ ⌊n/2⌋：在 n − k 步中挑出哪 k 步走 2 阶。测试以此作为独立的参考方法。dp[n] 也等于斐波那契数 F(n + 1)。

## 复杂度与实现

共 n 轮，每轮一次加法，时间 Θ(n)，额外空间 O(1)。保存完整的 dp 数组需要 Θ(n) 空间；记忆化递归同样只计算 n + 1 个状态，但递归深度为 n。

dp[n] 的二进制位数约为 0.69n。Python 大整数加法的成本随位数增长，大 n 时按位计算的总时间为 O(n²)。C++ 返回 `std::uint64_t`，要求结果可表示，即 n ≤ 92。窗口最后一次只计算到 dp[n]，不会为了一个用不到的 dp[n + 1] 提前溢出。

Python 用 `functools.reduce` 折叠 `range(n)`，C++ 用 `std::ranges::fold_left` 折叠 `iota`，两者每步都把旧窗口映射为新窗口。

若需要更快，可用矩阵快速幂或快速倍增在 O(log n) 次乘法内求 F(n + 1)。
