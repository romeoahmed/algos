# Karatsuba 大整数乘法

## 问题

精确计算两个非负整数 x、y 的乘积，支持上千位操作数。

- Python 接收非负 `int`，返回 `int`。
- C++ 接收非空 ASCII 十进制数字串，允许前导零，返回无前导零的十进制字符串；零统一返回 `"0"`。

两种接口都保留输入，位数不受固定宽度整数限制。Python 使用任意精度整数，C++ 用字符串保存全部数位。

## 思路

先把两个数拆成高、低两块。例如 1234 = 12×100 + 34。设进制为 B，取 m 为较长操作数位数的一半，则

$$
x=aB^m+b,\qquad y=cB^m+d.
$$

a、c 是高位块，b、d 是低位块。直接展开乘积：

$$
xy=acB^{2m}+(ad+bc)B^m+bd.
$$

这需要 ac、ad、bc、bd 四次递归乘法。关键是中间项只需要 ad+bc 的和，可以一起算：

$$
ad+bc=(a+b)(c+d)-ac-bd
$$

于是，先算高位乘积、低位乘积和“两块之和的乘积”，再用加减法还原交叉项：

$$
z_2=ac,\quad z_0=bd,\quad
z_1=(a+b)(c+d)-z_2-z_0,
\qquad xy=z_2B^{2m}+z_1B^m+z_0.
$$

每次递归都少算一次乘法，额外工作只是加减和移位。高低块之和可能因进位多一位，仍交给递归处理；两个操作数不等长时，较短数的高位块可以是零。

## 伪代码

遵循[记号约定](../notation.md)。`DIGITS` 为基数 B 下的位数；`SHIFT(v, m)` 表示在低位补 m 个零。`SMALL` 表示两个数都落在固定小规模范围内。

```text
KARATSUBA(x, y)
    if x = 0 or y = 0
        return 0
    if SMALL(x, y)
        return x · y
    m ← ⌊MAX(DIGITS(x), DIGITS(y)) / 2⌋
    (a, b) ← (⌊x / Bᵐ⌋, x mod Bᵐ)
    (c, d) ← (⌊y / Bᵐ⌋, y mod Bᵐ)
    high ← KARATSUBA(a, c)
    low ← KARATSUBA(b, d)
    cross ← KARATSUBA(a+b, c+d) − high − low
    return SHIFT(high, 2m) + SHIFT(cross, m) + low
```

## 示例

十进制下，12×34 拆为 a = 1、b = 2、c = 3、d = 4：

- high = 1×3 = 3，low = 2×4 = 8。
- cross = (1+2)×(3+4)−3−8 = 10。
- 结果为 3×100 + 10×10 + 8 = 408。

这是三次乘法恒等式的演示；实际代码会直接在小规模基例计算此例。

```python
from src.karatsuba.solution import karatsuba

print(karatsuba(1234, 5678))  # 7006652
assert karatsuba(10**1000 - 1, 10**1000 + 1) == 10**2000 - 1
```

## 正确性

零和固定小规模基例直接返回正确乘积。对递归子问题归纳，high、low 和两个块之和的乘积均正确；上述恒等式给出 cross = ad+bc，移位组合因此等于 xy。

操作数非负，故 `(a+b)(c+d) ≥ ac+bd`。C++ 减去 high+low 时结果非负，十进制减法只需处理局部借位，无需引入带符号大整数。

对非基例，至少一个操作数跨越分块边界。对该数，高块、低块及两块之和都严格小于原数；另一个数的对应量不大于原数。因此以 x+y 为递归度量严格下降，递归终止。进位使位数偶尔不下降也不会破坏终止性。

## 复杂度与实现

设 n 为两个操作数的最大有效位数，按单个位的运算计价。每层有三个约半长的乘法，拆分、加减、移位和组合共需 O(n) 时间。忽略取整和进位带来的常数位差，递推为

$$
T(n)=3T(n/2)+O(n),
$$

最坏时间为 Θ(n^log₂3)，指数约为 1.585，小于竖式乘法的 2。严格说，子问题最多有 ⌈n/2⌉+1 位，这个常数位差不改变渐近界。零输入可以提前返回。

三个子调用依次执行，每层保留 O(n) 位数据。沿递归路径，长度近似为 n、n/2、n/4、……，总和为 O(n)，因此计入输出和临时结果的峰值额外空间为 O(n)，递归深度为 O(log n)。这里已计入大整数加减、移位和复制的成本。

两种语言使用同一恒等式，按各自的数据表示选择进制：

- Python 用二进制，以 `bit_length` 确定拆分点，通过移位和掩码取高低块。两个数都至多 8 位二进制时直接相乘。算法不做十进制字符串转换，不受相应的转换位数限制影响。
- C++ 用十进制，`string_view` 表示高低块。两个数都至多两位时，用 `fold_left` 解析后相乘，结果最大为 9801。其余计算由逐位加减和末尾补零完成。

C++ 加减法通过 `views::reverse` 从低位向高位处理进位、借位。减法接收并复用递归乘积的字符串，去前导零和补零都在局部缓冲区完成。子视图只在来源字符串存活时使用，临时加法结果会活到递归调用返回；最终输出独立拥有数据。原输入若有大量前导零，还需 O(L) 时间扫描，L 为原始字符串总长。

三个子结果都要参与组合，因此采用普通递归。Python 受递归上限限制，C++ 受栈空间限制，不依赖尾调用优化。这是展示分治结构的实现，未针对极度不等长输入或硬件调优。

测试以 Python 内建整数乘法和 C++ 独立竖式乘法核对结果，覆盖进借位、奇数位、不等长、前导零和千位混合数字；还检查 C++ 输入视图边界及结果独立性。
