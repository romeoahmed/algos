# 划分字母区间

## 问题

给定仅含小写 ASCII 字母的字符串，将它分成尽可能多的连续非空片段，使同一字母的所有出现都在同一片段内。返回各片段长度，按原文顺序排列。空字符串返回空序列。

## 思路

每读到一个字母，就多了一条约束：当前片段必须包含这个字母最后一次出现的位置。把所有已见字母的要求合起来，取最远的位置，就是这段最早可能结束的地方。

先记录末位置 last，再依次计算 `last[letter] + 1` 的前缀最大值，也就是“从开头到当前位置见过的最大值”。加 1 是为了得到不包含右端点的边界 stop。当 `i + 1 = stop`，所有已见字母都已出现完，可以立即切开。相邻切点相减，就是片段长度。

只看当前字母是否结束会误切。例如 `abac` 中 b 在下标 1 已最后出现，但 a 还会在下标 2 出现，第一段必须至少是 `aba`。

## 伪代码

PREFIX-MAX 从左到右累计最大值，例如 `[3, 2, 3, 4]` 得到 `[3, 3, 3, 4]`；空输入得到空序列。中间序列可边遍历边计算，无需全部保存。

```text
PARTITION-LABELS(text)
    last ← 每个字母的最后出现位置
    stops ← PREFIX-MAX([last[letter] + 1 : letter ∈ text])
    cuts ← [0] ⧺ [i + 1 : i ∈ [0:|text|), stops[i] = i + 1]
    return [cuts[j + 1] − cuts[j] : j ∈ [0:|cuts| − 1)]
```

## 示例

先看短例子 `abac`：

| 下标 i | 字母 | 该字母末位置 + 1 | 最远边界 stop | 此处能否切分         |
| ------ | ---- | ---------------- | ------------- | -------------------- |
| 0      | a    | 3                | 3             | 否，后面还有 a       |
| 1      | b    | 2                | 3             | 否，仍需包含后面的 a |
| 2      | a    | 3                | 3             | 是，切在 3           |
| 3      | c    | 4                | 4             | 是，切在 4           |

切点连同起点为 `(0, 3, 4)`，相邻相减得到长度 `(3, 1)`。课件中的长例子 `ababcbacadefegdehijhklij` 则划分为 `ababcbaca | defegde | hijhklij`，长度为 `(9, 7, 8)`。

## 正确性

不变量：stop 等于所有已见字母的最后位置加一的最大值。取最大值的更新保持此性质。先前已闭合片段的边界不大于当前片段起点，所以全局前缀最大值也恰是当前片段所需的边界。

若 i + 1 < stop，至少一个已见字母还会在后面出现，此处切分不合法；若 i + 1 = stop，片段内所有字母在后面均不再出现，此处切分合法。因此算法总在最早合法边界切分。

任一合法划分的首段不能早于该边界结束。若它结束得更晚，可在此边界加一刀，不破坏字母约束且增加片段数。所以最优划分必须在这里切开。对剩余后缀归纳，得到最多片段，并确定唯一的长度序列。

## 复杂度与实现

设字符串长为 n，片段数为 p，每个非空片段至少包含一种独有字母，所以 p ≤ 26。

Python 用字典推导式记录末位置，`accumulate(max)` 产出前缀最大值，生成器筛选切点，`chain` 补上起点 0，`pairwise` 将相邻切点配对，再逐对相减。中间迭代器各遍历一次，最终一次性构造元组，不反复拼接已有结果。

C++ 用固定数组记录末位置，以 `ranges::fold_left` 合并前缀扫描、切点判定和长度输出：状态包含当前起点、最远边界和结果向量，按值传递并移动向量，仅在调用内部尾部追加。不另存前缀最大值或切点序列。

两种实现时间均为 O(n + 1)，额外空间 O(26 + p)，包含输出；固定字母表下为 O(1)。均无递归。C++ 的 `string_view` 只在调用内访问，不逸出；返回向量与输入无共享所有权。若扩展字符集，需另计末位置表与输出空间。
