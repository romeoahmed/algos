# 有效的括号

## 问题

给定只含 `(`、`)`、`[`、`]`、`{`、`}` 的字符串 s，判断括号是否有效：每个右括号都与它前面一个同类的左括号配对，配对按嵌套顺序闭合，且没有未配对的括号。空串有效。

对应 LeetCode 20。

## 思路

从左到右读，已读部分中尚未配对的左括号排成一个序列。下一个右括号只能与其中**最近**的一个配对：若与更早的左括号配对，夹在中间的未配对左括号就会跨过这对括号，嵌套被破坏。最近加入的先处理，这正是栈的后进先出。

栈里不必保存左括号本身，可以直接保存它期待的右括号，也就是“还欠着的右括号”。读到左括号就压入对应的右括号；读到右括号，栈顶必须恰好是它，然后弹出。失败只有三种：

- 右括号到来时栈为空：多出一个右括号；
- 栈顶与右括号不同：类型不符，或闭合顺序交叉，如 `([)]`；
- 读完后栈非空：有左括号没有闭合。

## 伪代码

遵循[记号约定](../notation.md)。

```text
VALID-PARENTHESES(s)
    S ← []    // 栈：尚未闭合的左括号所期待的右括号
    for c in s
        if c 是左括号
            PUSH(S, CLOSER(c))
        else if S = [] or POP(S) ≠ c
            return False
    return S = []
```

CLOSER 把 `(`、`[`、`{` 分别映射为 `)`、`]`、`}`。短路求值保证只在栈非空时 POP。

## 示例

s = `{[()]}`，栈从底到顶：

| 读入 | 动作   | 栈      |
| ---- | ------ | ------- |
| `{`  | 压入 } | `}`     |
| `[`  | 压入 ] | `} ]`   |
| `(`  | 压入 ) | `} ] )` |
| `)`  | 弹出 ) | `} ]`   |
| `]`  | 弹出 ] | `}`     |
| `}`  | 弹出 } | 空      |

读完时栈空，有效。`([)]` 读到 `)` 时栈顶是 `]`，无效；`((` 读完后栈非空，无效；`)` 第一步就遇到空栈，无效。

## 正确性

有效串可以递归定义：空串有效；若 A、B 有效，x 是左括号、x′ 是对应的右括号，则 x A x′ B 有效。

关键引理：从任意栈 σ 开始处理一个串 u，若途中从不弹出 σ 中原有的元素，则 u 的处理结果与从空栈开始相同，结束时栈为 σ 接上 u 单独处理剩下的部分。这是因为栈只在顶端变化，σ 只是垫在底下。

- **有效串都被接受。** 对长度归纳。空串显然。设 s = x A x′ B：压入 x′ 后栈为 [x′]；由归纳 A 从空栈处理不会失败且最终栈空，由引理从 [x′] 处理 A 后栈仍为 [x′]；读到 x′ 时栈顶相符，弹出后栈空；再由归纳 B 被接受。
- **被接受的串都有效。** 对长度归纳。设 s 非空且被接受，首字符必为左括号 x（否则第一步就遇到空栈），读完时栈空，所以 x 压入的 x′ 必在之后某处被一个相同的右括号弹出。中间的子串 A 从 [x′] 开始处理，从未弹出 x′，并在结束时回到 [x′]，由引理 A 从空栈处理也不失败且最终栈空，即 A 被接受。剩下的 B 从空栈开始处理并被接受。由归纳 A、B 有效，s = x A x′ B 有效。

测试反复删去相邻的 `()`、`[]`、`{}`，能删空即有效，作为独立的参考方法。删去或插入一对相邻的同类括号不改变有效性；有效的非空串必含这样一对（最内层的一对），所以有效串都能删空；反过来，把删空的过程倒过来，就是由空串逐对插入构造出原串。

## 复杂度与实现

每个字符至多入栈、出栈一次，时间 Θ(n)；全是左括号时栈深 n，额外空间 O(n)。

输入若含括号以外的字符，它会被当作右括号处理；栈中只可能是 `)`、`]`、`}`，比较必然失败，所以这样的输入判为无效。两种语言行为一致。

Python 用列表作栈，只使用 `append` 和 `pop`。C++ 用 `std::stack<char>`，它只暴露栈顶操作，编译器保证实现没有越过栈的接口；`pop` 不返回值，需要先 `top` 再 `pop`。
