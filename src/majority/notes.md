# 多数元素

## 问题

输入为非空整数序列，保证某个值出现次数严格超过 n/2。返回该多数元素。

对应 LeetCode 169。

## 思路

Boyer–Moore 投票法维护候选值 c 和余额 b。每读入一个值 x，若 b = 0，先令 c = x；随后 x = c 时余额加 1，否则减 1。

直观地看，每次把两个不同的值配成一对一起删去。多数元素比其他所有元素加起来还多，就算每次都拿它去抵消别的值，也不可能被消完。余额 b 记录的是目前尚未被抵消的候选 c 的个数；b = 0 表示已读前缀恰好两两抵消，下一个值成为新候选。

## 伪代码

遵循[记号约定](../notation.md)。

```text
MAJORITY(A)
    c ← 0; b ← 0
    for x in A
        if b = 0
            c ← x
        if x = c
            b ← b + 1
        else
            b ← b − 1
    return c
```

初始 c = 0 仅为占位，第一个元素会覆盖它。

## 示例

处理 `[2, 2, 1, 1, 1, 2, 2]` 时，状态 `(c, b)` 依次为：

```text
(2, 1) → (2, 2) → (2, 1) → (2, 0)
       → (1, 1) → (1, 0) → (2, 1)
```

最终候选为 2。

## 正确性

不变量：已扫描的前缀可以分成若干对互不相同的元素，以及 b 个都等于 c 的剩余元素。读入 x 时，若 b = 0 或 x = c，x 加入剩余部分；否则 x 与一个剩余的 c 配对，二者不同。两种情况都保持不变量。

设多数元素为 m，出现 t > n/2 次。每一对中至多有一个 m，而对数不超过 (n − b)/2 ≤ n/2 < t，所以 m 不可能全部落在对中，至少有一个 m 在剩余部分里。剩余部分全都等于 c，故 c = m。

## 复杂度与实现

单次遍历，时间 Θ(n)，额外空间 O(1)。

投票函数将旧状态和当前值映射为新状态。Python 用 `functools.reduce`，C++ 用 `std::ranges::fold_left`，均按输入顺序折叠。Python 接受 `Iterable[int]`，会完整消耗迭代器输入。
