# 伪代码约定

采用《算法导论》（CLRS）第 4 版的结构化伪代码风格，统一使用 **0 起始下标、半开区间**。

## 记号

| 记号                   | 含义                    |
| ---------------------- | ----------------------- |
| 四空格缩进             | 代码块                  |
| `←`、`=`               | 赋值、相等判断          |
| `\|A\|`、`A[i]`        | 序列长度、第 i 项       |
| `A[l:r]`               | 左闭右开的子序列        |
| `[]`、`⧺`              | 空序列、顺序拼接        |
| `(a, b)`               | 有序对，也用于多返回值  |
| `[f(x) : x ∈ A, P(x)]` | 按原顺序筛选并映射      |
| `⌊x⌋`                  | 向下取整                |
| `x ↦ f(x)`             | 将 x 映射为 f(x) 的函数 |

`for i ← a to b` 包含两端；a > b 时不执行。逻辑表达式短路求值。

## 基础操作

`COPY` 复制序列，`APPEND` 在尾部追加元素，`SPLIT` 按分隔符切出连续片段，`INTEGER` 解析十进制整数，`MAX` 取最大值。`APPLY(op, a, b)` 执行指定的加、减或乘法。

递归表达子问题，函数组合表达数据流，局部步骤可用循环。切片表示数学子序列，是否复制取决于实现。函数保留输入，可修改局部副本；迭代器按遍历需要消耗。

## 分析约定

调用者保证输入满足各题前提。正确性用不变量或归纳法说明，两种语言采用相同算法思想。

n 表示输入长度，其他参数在各题定义。额外空间取峰值，计入输出、工作副本和递归栈。整数运算默认按单位成本计；大整数、字符串复制、哈希及输出规模的影响另行说明。

参考：[CLRS 第 4 版](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/)。
