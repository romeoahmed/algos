# 用栈实现队列

## 问题

只用栈的操作（压入、弹出、查看栈顶、判空与计数）实现先进先出的队列。队列支持 push（加入队尾）、pop（删除并返回队头）、peek（查看队头）、判空与计数；pop 和 peek 只在队列非空时调用。

对应 LeetCode 232。

## 思路

栈只能取到最新的元素，队列却要取最早的。把一个栈的元素逐个弹出、压入另一个栈，顺序整体颠倒：原来的栈底变成栈顶。于是用两个栈分工（实现中分别名为 inbox 与 outbox）：

- in 接收新元素，栈顶是最新的；
- out 负责出队，栈顶是最早的。

关键在于何时搬运。若 out 还有元素时就把 in 搬过去，较新的元素会压在较旧的元素上面，顺序就乱了。只有 out 为空时才能整体搬运：此时 in 中的元素都晚于已经出队的元素，翻转后正好接上。

这里维持一个更强的不变量：**out 为空当且仅当整个队列为空**。

- ENQUEUE：队列为空时直接压入 out，新元素同时就是队头；否则压入 in。
- DEQUEUE：弹出 out 的栈顶；若 out 因此变空，把 in 全部搬入 out。
- FRONT：读取 out 的栈顶，不修改任何栈。

常见写法在 pop 或 peek 发现 out 为空时才搬运，那样 peek 也可能修改结构。把搬运提前到 pop 之后，peek 就是只读操作，C++ 中可以声明为 `const`。

## 伪代码

遵循[记号约定](../notation.md)。ENQUEUE、DEQUEUE、FRONT 分别对应实现中的 push、pop、peek。

```text
ENQUEUE(Q, x)
    if Q.out = []
        PUSH(Q.out, x)    // 空队列：x 同时是队头
    else
        PUSH(Q.in, x)

DEQUEUE(Q)
    x ← POP(Q.out)
    if Q.out = []
        while Q.in ≠ []
            PUSH(Q.out, POP(Q.in))
    return x

FRONT(Q)
    return TOP(Q.out)
```

## 示例

依次执行下列操作，栈从底到顶书写：

| 操作   | 返回 | in       | out      |
| ------ | ---- | -------- | -------- |
| push 1 |      | `[]`     | `[1]`    |
| push 2 |      | `[2]`    | `[1]`    |
| push 3 |      | `[2, 3]` | `[1]`    |
| pop    | 1    | `[]`     | `[3, 2]` |
| push 4 |      | `[4]`    | `[3, 2]` |
| pop    | 2    | `[4]`    | `[3]`    |
| pop    | 3    | `[]`     | `[4]`    |
| pop    | 4    | `[]`     | `[]`     |

第一次 pop 后 out 变空，in 中的 3、2 依次弹出再压入，2 成为栈顶。之后的 4 进入 in，直到 out 再次清空才被搬运。出队顺序为 1、2、3、4。

## 正确性

不变量：把 out 从顶到底读、再接上 in 从底到顶读，恰好是队列从头到尾的元素序列；并且 out 为空时 in 也为空。

- ENQUEUE：若队列为空，x 进入 out，序列为 [x]；否则 out 非空，x 压在 in 顶部，正是序列末尾。两条性质都保持。
- DEQUEUE：队列非空，故 out 非空，其栈顶就是序列首项，弹出它。若 out 变空，剩余元素都在 in 中，从底到顶即从头到尾；逐个弹出并压入 out 后，out 从顶到底即从头到尾，in 变空，两条性质恢复。
- FRONT：out 非空，栈顶就是队头。

均摊分析：每个元素一生中至多压入 in、弹出 in、压入 out、弹出 out 各一次，共四次栈操作。因此任意 m 次操作的总代价为 O(m)，每次操作均摊 O(1)。单次 pop 最坏需要搬运整个 in，为 Θ(n)。

测试随机生成入队与出队序列，与标准库的队列（Python 的 `collections.deque`、C++ 的 `std::queue`）逐步比对返回值、队头和长度，作为独立的参考方法。

## 复杂度与实现

push、peek 和判空最坏 O(1)；pop 均摊 O(1)，最坏 Θ(n)；空间 Θ(n)。

Python 的 `StackQueue[T]` 是泛型类，两个列表只通过 `append`、`pop` 和 `[-1]` 当作栈使用，长度由 `len()` 给出。

C++ 的 `StackQueue` 保存 `int`，两个成员都是 `std::stack<int>`。`std::stack` 只暴露栈顶操作，所以实现不可能越过栈的接口。`peek`、`empty` 与 `size` 都是 `const` 成员函数；类保持值语义，复制队列会复制两个栈。
